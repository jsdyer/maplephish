How to read this

Public history contains derived PhishStats and URLhaus counts, with groups smaller than three pooled. It excludes raw URLs, identifiers and page titles. A brand-token match is a candidate, not confirmed impersonation. Registrar data is only displayed when explicitly supplied by your import; unknowns are not inferred. URLhaus records describe malware distribution and never become phishing counts.

Coverage and privacy

Filters and imports run in your browser. No pasted evidence is uploaded. The page fetches saved data from this site. Source links contact their named providers when opened. The CoolCode counter records aggregate opens, excluding input and filter values.
